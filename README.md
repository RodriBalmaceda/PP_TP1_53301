1. Clonar el repositorio:
   git clone https://github.com/RodriBalmaceda/PP_TP1_53301.git

2. Abrir el proyecto en IntelliJ IDEA.

3. En el panel de Project, hacer clic derecho sobre la carpeta "src" y seleccionar:
   Mark Directory as → Sources Root (debe quedar en azul).

4. Abrir la clase App.java y ejecutar con el botón verde ▶️.
